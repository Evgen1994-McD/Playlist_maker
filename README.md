## Playlist Maker

Краткое описание : Приложение для поиска треков, прослушивания музыки, составления плейлистов.

## Описаине :
Приложение позволяет искать треки по базе Itunes. Треки, которые понравлись, можно сохранить во внутреннюю Базу данных Room. 
Можно добавить трек в избранное.
Добавить в плейлист ( название и фото плейлискта можно выбрать, изображения сохраняются в память устройства).
Треки можно слушать в то время, как приложение свернуто ( реализован Bound Service + уведовление ) 

## Установка :
1. Скачайте репозиторий.
2. Откройте проект в Android Studio.
3. Запустить проект на эмуляторе. При необходимости, сгенерируйте APK.
